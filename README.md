# Vocalyze — integration and privacy layer

[**Deploy on Vercel →**](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fimzezsv-dot%2Fvocalyze&project-name=vocalyze&repository-name=vocalyze)  ·  [**Open a Hugging Face Space →**](https://huggingface.co/new-space?template=docker&sdk=docker)  ·  [Deploy guide](DEPLOY.md)  ·  [Delivery notes](DELIVERY.md)

Upload a meeting recording. Get back a speaker-attributed transcript and a
brief in which **every point carries the line it came from**.

This is the integration and privacy component of the Vocalyze project: the
FastAPI backend, the upload flow, the interface, the layer that merges the ASR,
diarization and LLM components into one system, and the privacy controls that
govern all of it.

---

## Run it

```bash
./run.sh
```

Then open <http://127.0.0.1:8000>. That is the whole setup — a virtualenv, an
encryption key and the service, with scripted models so nothing has to be
downloaded.

Manually, if you prefer:

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env
python -m app.core.crypto          # paste the key into ENCRYPTION_KEY in .env
uvicorn app.main:app --reload
```

`ffmpeg` is required for audio decoding (`apt install ffmpeg`, `brew install
ffmpeg`).

To see the finished output without uploading anything, open the running
service and press **See a finished example**. That sample is not hand-written:
it is generated by the real aligner, redactor, summariser and grounding
verifier (`python -m tools.make_demo`), and a test fails if it ever drifts
from what the pipeline currently produces.

### With real models

```bash
pip install -r requirements-models.txt
```

```ini
ASR_BACKEND=whisper
DIARIZATION_BACKEND=pyannote
HUGGINGFACE_TOKEN=hf_...          # accept the pyannote model terms first
SUMMARIZER_BACKEND=llm
LLM_BASE_URL=http://127.0.0.1:11434/v1
```

No code changes. The interface reads `/v1/capabilities` and stops calling
itself a demo.

## What it does

```
recording ─► normalize 16 kHz ─► Whisper ─► pyannote ─► align ─► summarize ─► verify ─► brief
                                                          │                      │
                                                    who said what      every claim cites a line
```

Three things this layer contributes beyond plumbing:

**Speaker attribution that survives real audio.** Whisper and pyannote
disagree about where words and turns begin. The aligner assigns each word to
the speaker whose turns cover most of it, breaks crosstalk ties in favour of
the tighter turn, smooths one-word flips, and marks a word that belongs to
nobody as unidentified rather than guessing. 100% word-level accuracy against
the fixture's ground truth.

**A brief you can check.** Every generated point is verified against the
transcript before it is shown: cited lines must exist, the wording must appear
in them, and every number must appear in the evidence. Unsupported points are
dropped and counted. In the interface, each point carries a chip — press it and
the transcript scrolls to the line it came from.

**Privacy enforced between the stages.** Audio is encrypted on arrival with a
key held for that job alone, and deleted as soon as it has been read.
Identifiers are redacted before storage and before anything reaches the
summariser. Transcripts cannot leave the machine unless that was configured.
Everything expires. Full detail and honest limits in
[`docs/PRIVACY.md`](docs/PRIVACY.md).

## Layout

```
app/
├── main.py                 FastAPI app, lifespan wiring, static interface
├── config.py               every setting, read from the environment
├── schemas.py              the contract shared by the UI, API and all three models
├── deps.py                 service container, job authorisation
├── worker.py               async job queue
├── api/
│   ├── jobs.py             upload, progress, result, exports, erasure
│   ├── privacy.py          policy, audit trail, chain verification
│   └── system.py           health, capabilities
├── core/
│   ├── crypto.py           AES-256-GCM, one data key per job
│   ├── store.py            encrypted job store, shredding, crypto-shred on erasure
│   ├── audit.py            hash-chained append-only trail
│   ├── retention.py        background expiry sweeper
│   ├── logging.py          filter that keeps transcript text out of logs
│   └── errors.py           errors that say what to do next
├── pipeline/
│   ├── orchestrator.py     the five stages, and the privacy steps between them
│   ├── align_core.py       word-to-speaker alignment  ← the core algorithm
│   ├── grounding_core.py   claim verification         ← hallucination control
│   ├── redaction.py        PII removal
│   ├── asr.py              ASRBackend + Whisper adapter
│   ├── diarization.py      DiarizationBackend + pyannote adapter
│   ├── summarizer.py       SummarizerBackend + LLM adapter + egress guard
│   ├── audio.py            ffmpeg probe and 16 kHz normalisation
│   ├── fixtures.py         the scripted meeting used by demo mode
│   └── registry.py         backend selection
└── web/                    the interface (no build step, no framework)
docs/                       PRIVACY.md · INTEGRATION.md · API.md
tests/                      alignment · grounding · redaction · privacy · API · deployment · model backends
tools/make_demo.py          regenerates the offline sample from the real pipeline
scripts/build_static.py     mirrors app/web/ into public/ for the edge CDN
api/index.py                serverless entry point for the Vercel deployment
```

## Tests

```bash
pytest
```

121 tests, about three seconds, no network and no model weights — they run
against the scripted backends, so the answer is the same on a laptop and in
CI.

| File | What it holds the code to |
|---|---|
| `test_alignment.py` | The edge cases real audio produces: boundary drift, crosstalk, silence nobody owns, a diarizer that returned nothing, ASR without word timings — and 100% word-level speaker accuracy against the fixture's ground truth. |
| `test_grounding.py` | The verifier rejects a claim nobody made, a citation to a line that does not exist, and an invented figure — and does not reject an uncited claim the transcript actually supports. |
| `test_redaction.py` | Identifiers removed, and meeting substance (budgets, dates, percentages, versions) left alone. Precision is tested as hard as recall. |
| `test_privacy.py` | The guarantees as assertions: stored bytes unreadable, a blob unmovable between jobs, erasure destroying the key, the sweeper expiring what it should, the audit chain catching an edit or a deletion, and the egress guard refusing an external summariser. |
| `test_api.py` | The whole contract through the real app — upload to erasure, every export format, every error envelope, and a job id alone granting nothing. |
| `test_deployment.py` | The published build: the serverless one-round-trip upload path, and the edge copy of the interface staying byte-identical to the served one. |

## Notes on the interface

One typographic system throughout — the Thmanyah typefaces, a fixed token
scale, and a single lead colour used as ink rather than fill. Body line-height
is 1.6 for Latin text; the type scale and the 8px spacing grid are the same
everywhere. Every rule uses logical properties (`margin-inline`,
`inset-inline-start`), so switching `dir="ltr"` to `dir="rtl"` on the `<html>`
element flips the whole interface with no second stylesheet.

The lead colour carries one meaning only — *checked against the transcript* —
and speaker identity is carried by a dot and a soft tint rather than coloured
bars, so six speakers never turn the page into a rainbow. Crosstalk and
unsupported claims are the only things allowed to use the alert colour.

No build step, no framework, no dependencies: three files served by the same
process as the API.
